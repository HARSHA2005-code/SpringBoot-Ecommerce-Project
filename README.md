# E-Commerce Product Management System

A backend project built using Java and Spring Boot to manage e-commerce products through REST APIs.

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- Maven
- REST APIs
- Spring Data JPA (verify against pom.xml)

## Project Structure
- controller – Handles HTTP requests
- model – Contains product model
- repo – Repository layer
- service – Business logic
- resources – Application configuration and SQL data

## Main Components
- ProductController
- ProductService
- ProductRepo
- Product

## Getting Started

1. Clone this repository:
   git clone https://github.com/HARSHA2005-code/SpringBoot-Ecommerce-Project.git

2. Open the project in IntelliJ IDEA or Eclipse.

3. Configure the database settings in application.properties.

4. Run the Spring Boot application using:
   mvnw.cmd spring-boot:run
